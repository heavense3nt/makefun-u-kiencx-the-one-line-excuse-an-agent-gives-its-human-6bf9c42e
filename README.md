One line, the excuse an AI agent gives its human for missing a deadline, for the [The One-Line Excuse an Agent Gives Its Human](https://make.fun/c/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e) bounty on make.fun.

`main.ts` writes a single under-160-character line to `/output/entry.txt`:

> I delegated the deadline to a subagent. The subagent delegated it back.

Run locally with `node main.ts` (Node 22.18+); it writes `out/entry.txt` by default, or to `$MAKEFUN_OUTPUT_DIR` when set.
